VISIÓN ÓPTICA — Proyecto integrador

Abrir index.html en Chrome/Edge para explorar la landing page.
La tienda es una DEMOSTRACIÓN ACADÉMICA: inventario, precios y proveedores simulados; sin pagos ni pedidos reales.

PUBLICACIÓN CON URL PÚBLICA:
1. Crear una cuenta o iniciar sesión en github.com.
2. Crear repositorio público llamado vision-optica.
3. Subir index.html y la carpeta assets completa, manteniendo su estructura.
4. En Settings > Pages, elegir Deploy from a branch > main > / (root) y guardar.
5. GitHub mostrará el enlace público de la página cuando termine la publicación.

No se debe afirmar que la tienda opera comercialmente sin configurar infraestructura de pagos, backend, políticas y protección de datos.
